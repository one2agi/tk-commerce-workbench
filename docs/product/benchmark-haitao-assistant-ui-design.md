> **文档状态**：已归档 / UI/UX 落地基准

> **适用项目**：`tk-commerce-workbench` 页面重构与体验对齐  
> **版本**：v1.0.0 (2026-10-01)

## 1. 整体设计语言与设计资产规范 (Design System Tokens)

对标产品采用的是典型的 **macOS 原生沉浸式浅色桌面工作台风格**（类似 Apple Design Guidelines + Linear/Raycast 现代轻量质感），其设计语言的核心特征是：**高信息密度、极低视觉杂音、明确的主次行动层级**。

```text
┌────────────────────────────────────────────────────────────────────────┐
│  海淘上架助手 - 妙手版 v1.1.8A                           [-] [□] [×]   │
├───────────┬────────────────────────────────────────────────────────────┤
│ [图标]    │ 状态标签栏: [全部 (23)] [未写入 (19)] [写入成功 (3)] ...     │
│ 商品处理  ├────────────────────────────────────────────────────────────┤
│ 图片选品  │ 筛选/搜寻区 | 批量操作区: [一键AI改图] [一键发布] [⚙️自动化] │
│ 写入记录  ├────────────────────────────────────────────────────────────┤
│ AI 模版   │ 高密度商品流转表格:                                        │
│ 系统设置  │ [ ] 缩略图 | 标题/来源 | 状态 | 图片进度条 | 写入状态 | 操作 │
│           │ [ ] 缩略图 | 标题/来源 | 状态 | 图片进度条 | 写入状态 | 操作 │
│           ├────────────────────────────────────────────────────────────┤
│ [配额/版本]│ 底部分页与统计: 已选 0 项 | 共 23 条 | [50条/页] [< 1/1 >]  │
└───────────┴────────────────────────────────────────────────────────────┘
```

### 1.1 配色方案 (Color Palette)
* **画布底色**：
  * 主视口底色：`#f8fafc`（Slate-50，极浅冷白灰，消除刺眼纯白反光）；
  * 卡片与表格底色：`#ffffff`（Pure White，形成微弱的层级分界）；
  * 侧边栏底色：`#f1f5f9` / `#ffffff`（细灰分割线 `border-slate-200`）。
* **品牌与主行动点**：
  * 主品牌蓝：`#2563eb`（Blue-600，高对比度，用于主按钮、Tab 高亮、单选高亮）；
  * 悬浮态蓝色：`#1d4ed8`（Blue-700）；
  * 柔和辅助蓝（背景）：`#eff6ff`（Blue-50，用于选中行、选中卡片）。
* **语义状态色（药丸与徽标）**：
  * **成功 / 写入完成**：背景 `#ecfdf5`，文本 `#059669`（Emerald-600）；
  * **处理中 / 正在生图**：背景 `#eff6ff`，文本 `#2563eb`（带流光动画或微弱渐变）；
  * **等待中 / 未处理**：背景 `#f1f5f9`，文本 `#64748b`（Slate-500）；
  * **警告 / 待确认**：背景 `#fffbeb`，文本 `#d97706`（Amber-600）；
  * **失败 / 阻断**：背景 `#fef2f2`，文本 `#dc2626`（Red-600）。

### 1.2 排版与尺寸栅格 (Typography & Spatial Rhythm)
* **字体栈**：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", PingFang SC, sans-serif`；
* **字号分阶**：
  * 标题/大卡标题：`15px` / `Font-Medium`；
  * 正文/表格主文本：`13px` / `Font-Regular`（保证高密度显示）；
  * 辅助说明/状态角标：`11px` ~ `12px` / `Font-Regular`；
* **圆角规范**：
  * 基础按钮与输入框：`rounded-md`（6px）；
  * 弹窗、抽屉卡片：`rounded-lg` / `rounded-xl`（8px ~ 12px）；
  * 状态药丸（Badge）：`rounded-full`（全圆角）。

## 2. 页面结构与导航架构 (Shell & Navigation)

系统采用 **左侧常驻紧凑导航栏 + 右侧主内容工作台** 的经典两栏架构。

### 2.1 左侧全局导航 (Sidebar)
* **宽度**：`200px`（折叠模式可收敛为 `64px` 图标模式）；
* **顶部品牌区**：
  * 产品名称：**海淘上架助手**，附带浅灰版本号 `v1.1.8A`；
* **菜单项列表 (单选选中态：浅蓝底 + 蓝色粗体 + 蓝色左边条)**：
  1. `[ 📦 商品处理 ]`：核心任务调度工作台；
  2. `[ 🖼️ 图片选品 ]`：本地文件夹拖拽与图片批量选品入口；
  3. `[ 📋 写入记录 ]`：妙手 ERP 写回履约日志与日历看板；
  4. `[ 🪄 AI 模版 ]`：品类属性预设与生图 Prompt 矩阵配置；
  5. `[ ⚙️ 系统设置 ]`：平台授权、店铺绑定、API 算力中转站配置；
* **底部账户卡**：
  * 当前卖家账号、授权有效期、算力余额/剩余额度。

## 3. 六大核心视图详细 UI 与交互规范

### 3.1 核心视图 1：商品处理总览台 (Task Table Workbench)

这是卖家停留时间最长的核心阵地。

```text
[全部 (23)] [待处理 (0)] [处理中 (0)] [未写入 (19)] [写入成功 (3)] [失败 (1)]
---------------------------------------------------------------------------------
[来源: 全部 ▼] [店铺: Temu半托-1 ▼] [🔍 搜索商品...]       [⚡一键AI改图] [🚀一键发布] [⚙️自动化设置]
---------------------------------------------------------------------------------
[ ] 商品信息                | 来源         | 状态       | 图片进度 | 写入状态   | 下一步   | 操作
---------------------------------------------------------------------------------
[✓] 🖼️ 1pc 玫瑰花雕像摆件... | Temu 半托-1  | AI生成完成 | [████ 4/5] | 正在写入... | 写入妙手 | [编辑] [写回] [删除]
    ID: 60104... 08/15 14:58 | (插件采集)   |            | (4/5 张)   |            |          |
```

1. **顶部状态切换选项卡 (Tabs)**：
   * 采用轻量下划线指示，直观展示各阶段数量：`全部 (23)`、`待处理 (0)`、`处理中 (0)`、`未写入 (19)`、`写入成功 (3)`、`写入失败 (1)`；
   * 点击切换瞬时过滤，无整页重刷。
2. **过滤与批量操作栏 (Action Bar)**：
   * 左侧：来源筛选器（Temu 采集 / 本地图片导入）、目标店铺下拉、商品名称/ID 快速过滤；
   * 右侧主行动组：
     * `[ ⚡ 一键 AI 改图 ]`：实心蓝按钮，为所有选中的未改图商品批量排队跑图；
     * `[ 🚀 一键发布 ]`：实心蓝按钮，批量推送到妙手待发布；
     * `[ ⚙️ 上架自动化设置 ]`：轻量灰色线框按钮，点击从屏幕右侧滑出抽屉。
3. **高信息密度数据表格 (Table Grid)**：
   * **行高**：`72px`，紧凑而不拥挤；
   * **列结构**：
     * **列 1 (复选框 + 核心物料)**：`48x48px` 原厂高清缩略图 + 2 行截断的重构标题 + 采集时间与原平台超链接（Hover 显示原图浮窗）；
     * **列 2 (来源/店铺)**：店铺标识徽标（如 `Temu 半托-1`）与抓取渠道；
     * **列 3 (处理状态)**：`AI生成完成`、`排队中`、`生成中` 药丸徽标；
     * **列 4 (图片处理进度)**：
       * 进度指示：彩色微型进度条（宽度 `80px`，高度 `6px`），绿色进度代表已产出张数（如 `4/5`）；
     * **列 5 (写入状态)**：
       * 未写入：灰色标签；
       * 写入中：蓝色文字 + 旋转动画 Spinner（`正在写入妙手采集箱...`）；
       * 写入成功：绿色标签 + 成功勾选；
       * 写入失败：红色标签 + Tooltip 悬浮展示具体错误（如“重量小于0.01kg”）；
     * **列 6 (操作区)**：
       * `[ 编辑 ]`：文本按钮，点击打开轻量质检抽屉；
       * `[ 写入妙手待发布 ]`：小尺寸实心蓝按钮，单件快速触发；
       * `[ 更多/删除 ]`：气泡菜单。
4. **底部分页器 (Pagination)**：
   * 常驻底部：展示当前选中条数、每页条数下拉（20 / 50 / 100）、总条数与页码快速切换器。

## 5. 前端工程落地质量约束

1. **零白屏与图片容错**：
   * 必须统一采用带有 SVG 骨架屏的 `<ImageThumbnail>`，若 S3/OSS 外链加载中或加载失败，优雅降级为占位符，绝不出现浏览器原生破损裂图；
2. **键盘无障碍与快捷操作**：
   * 质检弹窗支持 `Esc` 退出、`Enter` 确认写入、`← / →` 左右键快速切换 Hero 大图预览；
3. **响应式与无横向滚动条约束**：
   * 表格宽度通过 `table-layout: fixed` 与主列百分比自适应锁定，在 `1280px` 标准笔记本分辨率下保证 100% 视口内无横向滚动条。
