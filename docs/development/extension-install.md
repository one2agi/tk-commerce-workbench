# 浏览器扩展安装

1. 运行 `pnpm --filter @tk/extension build`，产物位于 `apps/extension/dist`。
2. Chrome/Edge 打开扩展管理页，启用“开发者模式”，选择“加载已解压的扩展程序”，指向该目录。
3. 在扩展设置中填写与服务端 `EXTENSION_TOKEN` 相同的 Bearer Token。Token 只保存在浏览器本地存储，不写入仓库。
4. 打开一个标准 1688 商品详情页：`https://detail.1688.com/offer/<商品ID>.html`。
5. 点击扩展图标，再点击“一键采集到工作台”。扩展只读取当前标签，不创建或关闭其他标签页。
6. 弹窗会显示价格、库存、SKU、主图、详情图和缺失项；部分成功可直接重新采集。
7. 详情稳定后，V3 采集契约会把实际 SKU 映射和其他结构化字段提交到 `/api/v1/local-captures`。
8. 同一批次的失败重试复用幂等键；采集成功后再次点击才生成商品的新版本。

升级本地扩展代码后，必须重新构建，并在扩展管理页点击“重新加载”。服务端会以 `409 extension_upgrade_required` 拒绝旧 V1/V2 采集数据。

扩展不绕过 1688 登录、验证码或风控，也不提供列表页或全店自动采集。
